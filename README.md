# Projeto de Agente Local

Este repositorio contem um projeto-base de agente local em Python na pasta `local_agent_starter`.

O objetivo da base e oferecer um assistente executavel com:

- leitura e analise de ficheiros
- criacao de conteudo e artefactos
- geracao de sites
- geracao de imagens com API multimodal opcional
- voz de entrada e saida
- monitoramento do workspace
- execucao controlada de comandos

Consulte [local_agent_starter/README.md](C:\Users\User\Documents\GitHub\-\local_agent_starter\README.md) para instalar e correr.
