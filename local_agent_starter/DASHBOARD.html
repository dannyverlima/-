🏗️ Arquitetura do Projeto

Estrutura de Diretórios

app/main.py - Interface CLI interativa com suporte a comandos diretos
app/agent.py - Loop do agente com tool calling e decisões inteligentes
app/tools.py - Registro de ferramentas com guardrails de segurança
app/media.py - Processamento de voz, áudio e imagem
app/site_builder.py - Gerador automático de sites HTML/CSS/JS
app/memory.py - Memória persistente em SQLite
app/dashboard.py - Servidor HTTP e interface web interativa
mcp/simple_server.py - Servidor Model Context Protocol de exemplo

💻 Comandos Disponíveis

python -m app.main
Inicia o modo chat interativo com o agente.
python -m app.main ask "sua pergunta"
Envia uma pergunta única ao agente e retorna a resposta.
python -m app.main doctor
Executa diagnóstico do ambiente e dependências.
python -m app.main dashboard
Abre o dashboard web interativo (porta 5173).
python -m app.main listen --seconds 5
Grava áudio do microfone e transcreve.
python -m app.main speak "seu texto"
Converte texto em voz usando TTS.
python -m app.main image --prompt "sua descrição"
Gera uma imagem PNG a partir de um prompt de texto.
python -m app.main site --project nome --title "Título" --brief "Descrição"
Cria um novo site base HTML/CSS/JS.
python -m app.main monitor
Monitora alterações no workspace com snapshot.
.\run_agent.cmd
Script Windows que cria venv, instala dependências e inicia o agente.

⚙️ Configuração

Variáveis de Ambiente (.env)

LOCAL_AGENT_MODEL - Modelo a usar (ex: qwen3:8b, llama2, mistral)
LOCAL_AGENT_BASE_URL - URL da API (ex: http://localhost:11434/v1 para Ollama)
LOCAL_AGENT_API_KEY - Chave de API (ex: "ollama" para Ollama)
LOCAL_AGENT_MULTIMODAL_API_KEY - Chave OpenAI para imagens/transcrição (opcional)
LOCAL_AGENT_ALLOW_WRITE - Permitir escrita em ficheiros (true/false)
LOCAL_AGENT_ENABLE_SHELL - Permitir acesso ao shell (true/false)

📋 Requisitos

Dependências do Sistema

Python 3.11+ - Versão mínima do Python
Ollama - Para modelos locais (opcional, se usar API remota)
